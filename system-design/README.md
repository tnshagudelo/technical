## The Big Questions in System Design

1. **How does it scale?** — horizontal vs. vertical scaling, sharding, partitioning
2. **What happens when a component fails?** — redundancy, replication, failover
3. **How consistent does it need to be?** — CAP theorem, eventual vs. strong consistency
4. **How fast does it need to be?** — caching strategies, CDN, read replicas
5. **How is data stored and retrieved?** — SQL vs. NoSQL, indexing, data modelling
