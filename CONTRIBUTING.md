# Contributing

Thank you for your interest in contributing to this repository!

## Adding a New Topic

1. Create a new folder at the root level using a descriptive, lowercase, hyphenated name (e.g., `concurrency`).
2. Add a `README.md` inside the folder explaining the topic, key concepts, and when to use them.
3. Include at least one code example. Place examples in a sub-folder named after the language (e.g., `python/`, `javascript/`).
4. Update the table in the root `README.md` with the new topic.

## Improving Existing Content

- Fix typos or factual errors via a pull request.
- Add more examples or alternative implementations.
- Add links to authoritative references at the bottom of the relevant `README.md`.

## Code Style

- Keep examples concise and focused on the concept being illustrated.
- Add comments to clarify non-obvious steps.
- Prefer standard library solutions over third-party dependencies unless the dependency is the point of the example.

## Pull Request Checklist

- [ ] New folder follows naming conventions
- [ ] `README.md` is present in the new/updated folder
- [ ] Root `README.md` table is updated (for new topics)
- [ ] Code examples run without errors
