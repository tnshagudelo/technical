# Sorting Algorithms

A comparison of common sorting algorithms — their mechanics, trade-offs, and when to use each.

---

## Algorithms Covered

| Algorithm | Stable? | In-Place? | Best Use Case |
|-----------|---------|-----------|---------------|
| Bubble Sort | ✅ | ✅ | Teaching / tiny datasets |
| Merge Sort | ✅ | ❌ | General purpose, linked lists |
| Quick Sort | ❌ | ✅ | General purpose, arrays |
