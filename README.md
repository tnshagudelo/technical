# technical

Repository of technical topics, learning and proof of concept.

A curated collection of notes, examples, and small projects covering a range of software engineering disciplines — used for study, experimentation, and building mental models.

## 📚 Topics

| Folder | Description |
|--------|-------------|
| [data-structures/](data-structures/) | Core data structures with explanations and code examples |

| [design-patterns/](design-patterns/) | Gang of Four and modern software design patterns |
| [system-design/](system-design/) | Scalability concepts, architecture diagrams, and case studies |

## 🚀 Getting Started

Each topic lives in its own folder and contains:

- A `README.md` with explanations and key concepts
- Code examples in one or more languages (Python, JavaScript, Go, etc.)
- Links to further reading

Browse the topic folders above, or clone the repo and explore locally:

```bash
git clone https://github.com/tnshagudelo/technical.git
cd technical
```
